An entry for make.fun's [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty ($2 in USDC): a program that writes one one-star review of Monday, written as if Monday were a restaurant — 25 words or fewer, on a single line.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The review is a genuine diner's complaint — the server brings the weekend back cold, forgets the coffee, and the bill comes to five working days — so the joke only works for Monday: the price of the meal is the whole working week ahead. The output is deterministic: every run writes the same line, 109 characters and 20 words, as the gate requires (1 line, 1–180 characters, at most 25 words).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
